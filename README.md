# 🌾 ফসল ডাক্তার (Crop Doctor)

একটা পাতার/ফসলের ছবি দিলে বাংলায় **রোগের নাম + কারণ + সার/ওষুধের পরামর্শ** দেয়।
পুরোটা **ফ্রি** — Google Gemini-র ফ্রি API দিয়ে চলে, কোনো মডেল ট্রেনিং লাগে না।

---

## ধাপ ১ — ফ্রি API key নিন
1. যান: https://aistudio.google.com/apikey
2. Google দিয়ে লগইন করে **"Create API key"** চাপুন।
3. key-টা কপি করে রাখুন (ফ্রি টিয়ারেই দিনে অনেকবার চলবে)।

## ধাপ ২ — key সেট করুন

**Windows (PowerShell):**
```powershell
$env:GEMINI_API_KEY = "এখানে-আপনার-key-বসান"
```

**Linux / Mac / Colab:**
```bash
export GEMINI_API_KEY="এখানে-আপনার-key-বসান"
```

## ধাপ ৩ — লাইব্রেরি ইনস্টল করুন
```bash
pip install -r requirements.txt
```

## ধাপ ৪ — চালান
```bash
python crop_doctor.py leaf.jpg
```
ফসলের নাম জানা থাকলে বললে আরও ভালো হয়:
```bash
python crop_doctor.py leaf.jpg --crop ধান
```
